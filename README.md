# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

做一个面向马术俱乐部蹄铁师的修蹄记录前端项目，可以记录马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄日期、下次复查日期和照片备注。页面需要有马匹列表、复查提醒、左右前后蹄对比记录、异常步态标记和蹄铁更换历史。

## 功能

- 按马匹编号新增修蹄记录；编号自动转大写，已有马匹可从输入框下拉选择。
- 左前 / 右前 / 左后 / 右后四个蹄位分别勾选并填写蹄形、步态问题、蹄铁类型、钉位、照片备注；步态问题留空即视为正常。
- 同一匹马的历次记录按修蹄时间倒序排在一起，最近一次高亮，方便回看上次用的蹄铁和钉位。
- 保存时若修蹄日期早于该马最近一次记录，弹出“日期冲突”提示，原记录完整保留；可选择返回修改，或作为历史补录追加（仍不覆盖任何旧记录）。
- 复查提醒区分已逾期 / 今天 / 7 天内临近；异常步态的马在提醒和马匹列表中红色标记并置顶，点击提醒可直接跳到对应档案。
- 数据通过 localStorage 保存在本机浏览器，支持按编号搜索、前后蹄 / 异常步态 / 待复查筛选、导出 CSV（每蹄一行）。
- 首次打开自带示例档案（HORSE-18、27、31、04），侧栏可一键恢复示例数据。
